# Aston Martin Valkyrie AMR Pro Audio Assets

Place authentic, licensed Cosworth V12 audio recordings here:

- `valkyrie-v12-start.mp3` — Engine ignition, starter motor crank, and settling into 1,400 RPM idle.
- `valkyrie-v12-rev.mp3` — High-rev throttle sweep climbing towards the 11,100 RPM redline.

The web application automatically detects when these files are present and enables the interactive V12 cockpit acoustic controls.
